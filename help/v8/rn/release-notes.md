Adobe Campaign Web 使用者介面版本會在持續傳遞模型上運作，透過該模型可採用更具擴充性、分階段的方式來部署功能。 因此，這些發行說明每月會更新多次。 請定期進行檢查。

### 功能改進 {#26-8-improvements}

* **開啟追蹤**：您現在可以直接從Campaign網頁使用者介面啟用或停用開啟追蹤。 這可協助您遵守資料保護規範。
* **方案清單檢視**：方案現在會列在專用檢視中，類似於行銷活動、傳遞和工作流程。 您可以瀏覽現有的程式，並直接從這個檢視建立新的程式。
* **自訂結構描述組態**：在&#x200B;**動作資料**&#x200B;區段中，您現在可以不允許自訂結構描述記錄上的&#x200B;**重複**&#x200B;動作。
  <!--* **Workflow and delivery templates (only msf???)**: When creating a new workflow or delivery, you must now explicitly select a template. A default template is no longer applied automatically.-->
* **自訂篩選器**：在結構描述編輯器中，自訂篩選器現在支援直接連結的篩選條件，而且您可以使用新的&#x200B;**自訂篩選器設定**&#x200B;覆寫任何屬性的預設標籤。
* **結構描述驗證**：您現在可以使用新的&#x200B;**驗證**&#x200B;按鈕，直接從結構描述編輯器驗證結構描述的結構。
* **資料夾安全性**：當使用者具有&#x200B;**插入**&#x200B;或&#x200B;**編輯**&#x200B;存取許可權時，**重新命名**&#x200B;選項現在可用於資料夾。
